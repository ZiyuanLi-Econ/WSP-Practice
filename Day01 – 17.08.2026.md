## Shortcuts

- `Ctrl + 1`: Open Format Cells. This also provides access to **Center Across Selection** for centering a heading across multiple cells.
- `Ctrl + [`: Trace precedents to see where a result comes from.
- `F9`: While editing a formula, temporarily calculate a selected part of the formula. Press `Esc` after checking the result.
- `Alt + Shift + →`: Create a group.
- `Alt + Shift + ←`: Ungroup.
- `Ctrl + F`: Find content. This can also help check whether a worksheet is referenced elsewhere in the workbook.
- `Ctrl + S`: Save. Save frequently while modeling and retain separate versions as the model develops.

## Modeling Discipline

1. **One input, one source.** Enter each assumption only once and reference that cell everywhere else. Do not repeat the same assumption in multiple locations.
2. **One calculation, one source.** If a result has already been calculated, reference it instead of calculating it again. Whenever a value can be calculated, do not hardcode it. For example, Total Assets should be the sum of the underlying asset items.
3. **Do not bury assumptions inside formulas.** A tax rate should sit in a separate assumption cell instead of being embedded as `× 0.65`. Mathematical constants, such as the `1` in `1 + WACC`, can remain inside the formula.
4. **Avoid oversized formulas.** Break complex calculations into clear steps so that the model is easier to read, review, and debug.
5. **Follow color conventions:**
   - Blue = hardcodes and inputs
   - Black = calculations within the same worksheet
   - Green = links to another worksheet in the same workbook
   - Red = links to an external Excel file
6. **Use Group instead of Hide whenever possible.** Grouping makes it clear that collapsed data still exists.
7. **Avoid daisy chains.** Where possible, have each forecast period reference the original source assumption rather than linking through `A → B → C → D`. A simple horizontal straight-line forecast can be an exception.
8. **Avoid named cells and named ranges.** Standard cell references are generally easier to trace and audit.
9. **Minimize links to external workbooks.** External Excel links can break when files are moved, renamed, or unavailable.
10. **Avoid black boxes.** A model should be transparent, traceable, and auditable rather than producing an unexplained output from a set of inputs.
11. **Use Center Across Selection instead of Merge Cells** when a heading needs to be centered across multiple columns.
12. **Use footnotes for the final reader and comments for internal documentation.** Comments are useful for recording sources, page numbers, and other audit details.
13. **Check downstream dependents before deleting an entire worksheet or module** to avoid creating `#REF!` errors.
14. **Do not split the model across too many worksheets.** Wall Street generally prefers fewer, longer worksheets organized by functional module rather than a separate worksheet for every small calculation.
15. **Centralize assumptions wherever possible.** The model should remain usable and understandable even when the original modeler is not available.

## Case Preparation

1. **Collect formal company disclosures:**
   - **10-K:** Complete annual financial data and formal disclosures.
   - **Press Release:** More timely earnings highlights, non-GAAP metrics, and guidance.
   - **Conference Call Transcript:** Management explanations, forward-looking views, and analyst Q&A.
   - For quarterly or LTM modeling, also collect the latest **10-Q**.
2. **Find recent equity research reports and forecasts:**
   - **Equity Research Report:** The forecasts, reasoning, and company drivers published by an individual analyst or institution.
   - **Consensus Estimates:** Aggregated market expectations from multiple analysts, useful as a benchmark and sanity check.
   - For a quick introduction to an unfamiliar industry, prioritize an **Initiating Coverage Report**.
3. **Review approximately six months of important news,** including M&A, stock splits, and other material changes.
4. **Compile the public information into a PIB (Public Information Book)** as the supporting information base for the model.

## Three-Statement Modeling Workflow

`PIB / Historical Data → Input into Excel → Forecast Income Statement → Forecast Balance Sheet → Derive Cash Flow Statement → Resolve Circular References → Scenario & Sensitivity Analysis`
